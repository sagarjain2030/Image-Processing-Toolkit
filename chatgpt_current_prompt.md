Responsibilities:

We previously renamed `pages/` to `views/` to avoid conflicts with Streamlit's built-in multipage convention.

Do not redesign these responsibilities unnecessarily.

## 3. Important recent decision: independent image uploading

We deliberately changed our earlier shared-upload design.

**Every page must have its own independent uploader. When navigating to another page, the previously uploaded image must be cleared.**

Expected behavior:

- Home: upload Image A.
- Function1: uploader starts empty; upload Image B.
- Function2: uploader starts empty.
- Return to Function1: Image B must be gone.
- Return to Home: Image A must be gone.

We do not want upload-generation counters or additional session-state management.

Instead, each view calls a shared `load_image(main_content, key)` function with a unique fixed widget key.

Only the selected view renders during a Streamlit run, allowing Streamlit to clean up inactive widget state.

Keep this approach unless actual UI testing shows a problem.
